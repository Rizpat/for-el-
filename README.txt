FOR EL — DARK ROMANTIC WEBSITE

Kode rahasia: 091023 (ubah SECRET_CODE di script.js bila perlu).

FOTO:
Masukkan foto ke assets/images/ dengan nama memory1.jpg sampai memory6.jpg. Jika foto PNG, ubah nama src pada index.html agar cocok.

GITHUB PAGES:
1. Ekstrak ZIP.
2. Buat repository GitHub bernama for-el.
3. Upload isi folder ini ke root repository (jangan upload ZIP saja).
4. Repository > Settings > Pages > Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Setelah publish, buka link yang ditampilkan oleh GitHub Pages.
7. Buat QR Code dari link yang sudah dites di HP.

CATATAN:
Website tidak menggunakan musik. Tombol ajakan hanya menampilkan pesan di layar; tidak mengirim notifikasi ke pembuat. Kode di website statis bukan keamanan sungguhan. Anggap foto yang diunggah bisa diakses publik, terutama jika repository publik.
